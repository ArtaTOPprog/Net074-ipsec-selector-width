# Проверка подготовленного комплекта

Дата: 18 ноября 2026 года. Среда локальной проверки: Windows, CPython 3.12.14.

| Проверка | Результат |
| --- | --- |
| `python -m unittest discover -s tests -p test_suite.py -v` | 9 тестов успешно |
| Локальный UDP-обмен на `127.0.0.1` внутри тестов | 20 отправок, 20 приёмов, 20 echo-ответов |
| Повторная обработка `data/legacy` | 45 прогонов, 225 агрегатных сравнений, без расхождений |
| Сверка открытых UDP по ID, назначению и содержимому | 13 600 ожидаемых пакетов, без пропусков, дубликатов и несовпадений |
| `check_reference.py` | Совпали все 6 файлов результатов |
| Документы в Microsoft Word и экспортированный PDF | Статья: 10 страниц; эксперимент: 21 страница |
| Постраничный просмотр вёрстки | Проверены таблицы, подписи, изображения, содержание и номера страниц |

Команды воспроизведения находятся в [README](../README.md). Локальная проверка UDP подтверждает работу программ на одном компьютере. Она не измеряет работу VPN, нагрузку Cisco/ESR или доставку через реальный стенд.

Workflow `.github/workflows/tests.yml` подготовлен для Ubuntu и Windows. Его запуск в пользовательском GitHub ещё не выполнен. Проверка синтаксиса `capture.sh` не заменяет запуск tcpdump на Linux с нужными правами.

Для проверки исходных данных сохранены SHA-256 в `results/reference/sha256.csv`. Файл `MANIFEST.sha256` описывает содержимое публикуемого комплекта, кроме самого манифеста. Любое изменение документов или кода требует обновления этого файла.
