| --- | --- |

| Сравнение TAR и исходного ZIP | Все пять исходных скриптов совпадают по SHA-256 |
| Оригинальный gen.py | Байты сохранены без изменения |
| Проверка Python и новых путей imports | Синтаксис всех Python-файлов корректен; 8 тестов без сетевого обмена прошли |
| Историческая цепочка analyze.py → stats.py | Обработаны все 45 PCAP; Y1/Y2/Y3 совпадают со строгим разбором с точностью округления 0,001 процентного пункта |
| Строгий анализ PCAP/ICMP/ID | Совпали все 6 эталонных файлов |

| Упаковка | Проверены CRC ZIP, обязательные скрипты, относительные Markdown-ссылки и контрольные суммы |

До перестановки файлов полный набор из 9 тестов, включая localhost UDP, проходил локально. После этой перестановки сетевой тест и Bash-скрипты в текущей изолированной Windows-среде не выполнялись: запуск Git Bash блокируется средой, а доступ к стенду отсутствует. Проверена эквивалентная последовательность вызовов analyze.py → stats.py на всех 45 PCAP. Реальный сбор трафика через run.sh требует Ubuntu и настроенного стенда. GitHub Actions сохраняет запуск полного набора из 9 тестов на Ubuntu/Windows.

Историческая обработка условно определяет ESP-классы по длинам. Нулевой недосчёт в одной точке WAN не означает доказанных нулевых потерь у приложения. Для результатов исправленной статьи используется scripts/audit_legacy.py.
