# Исходные данные и единицы измерения

Основная серия содержит ровно 45 PCAP: S1–S3, по 15 прогонов. Файлы из старой резервной папки old исключены. В `data/legacy/gt.csv` находится 225 записей по пяти классам. Все исходные PCAP перенесены без изменения байтов.

`results/reference/sha256.csv` содержит SHA-256 каждого PCAP; пути в этом файле отсчитываются от `data/legacy`. `MANIFEST.sha256` в корне репозитория охватывает публикуемые файлы. Сам файл manifest не включает собственную контрольную сумму.

| Результат | Назначение |
| --- | --- |
| `runs.csv` | Метрики и качество наблюдения по каждому прогону |
| `statistics.csv` | Средние, СКО и 95 % t-интервалы при n=15 |
| `icmp_evidence.csv` | PCAP, номер кадра, внешние и вложенные поля ICMP |
| `plain_packet_validation.csv` | Проверка всех 13 600 открытых тестовых пакетов |
| `sha256.csv` | Контрольные суммы исходных захватов |
| `audit.json` | Сводка и границы доступных доказательств |

VESP, Vplain и VWAN измерены по IPv4 Total Length исходящих тестовых пакетов на WAN ESR-A. Это не полный объём всего WAN-обмена: служебные пакеты, канальные заголовки и другие участки маршрута не входят в эти суммы. Y1, Y2 и Y3 сначала рассчитаны внутри каждого прогона, затем усреднены по 15 прогонам. Mreturn относится к открытому обратному трафику и не доказывает приём приложением.

В старой серии отсутствуют отдельные журналы приёмника и независимые PCAP до шифрования и после расшифрования. Классы ESP выводятся по заранее различённым длинам. Обработка по SPI и Sequence Number проверяет внешние идентификаторы ESP, но не раскрывает внутренний UDP ID.

Во всех 45 файлах нет неизвестных ESP-длин, дубликатов SPI/Sequence Number, внутренних пропусков последовательности внутри наблюдаемой SA, усечённых IPv4 или фрагментов. В 39 прогонах виден один исходящий SPI, в шести — два. Эти признаки не позволяют объявить нулевые сквозные потери.
