# Дополнительные испытания: ещё не запускались на исходном стенде

Эти программы добавлены при доработке методики. На скриншотах Ubuntu они отсутствуют и для исходных 45 прогонов не нужны.

| Файл | Для чего подготовлен |
| --- | --- |
| `traffic_v2.py` | Общий план S1/S2/S3, пакетные ID, отправитель и UDP echo-приёмник |
| `validate_v2.py` | Сверка sender/receiver и независимых plaintext-PCAP |
| `schedule.py` | 15 блоков с балансом порядка селекторов |
| `score_audit.py` | Оценка решений относительно независимой разметки |
| `capture.sh` | Захват tcpdump на Linux и сохранение счётчиков потерь захвата |

`validate_v2.py` использует общий разборщик `scripts/pcapio.py`; запускайте его из полного репозитория. Подробный протокол: [reproducibility.md](../docs/reproducibility.md). Наличие инструментов не означает выполнения новых измерений.
